# صحنه | مدیریت تولید تئاتر — نسخه ۱.۲

وب‌اپ فارسی و راست‌چین با ظاهر Liquid Glass بنفش، برای مدیریت شخصی تولید تئاتر.

## امکانات
- نمایش‌ها، اعضای گروه، تمرین‌ها و اجراها
- دفتر مالی درآمد و هزینه
- ۴۵ تم رنگی جدید به‌علاوه تم بنفش اصلی
- درخواست نام در اولین ورود و پیام خوش‌آمدگویی شخصی
- جمله انگیزشی روزانه (از مجموعه ۴۵ جمله؛ روزانه بر اساس تاریخ تغییر می‌کند)
- تقویم ماهانه با نمایش تمرین‌ها و رویدادهای هر روز
- دفتر یادداشت با ساخت، ویرایش، جست‌وجو و حذف
- فهرست کارها با وضعیت انجام‌شده/در انتظار
- پشتیبان‌گیری و بازیابی JSON
- طراحی واکنش‌گرا برای موبایل و دسکتاپ
- بخش «درباره» با اعتبار «طراحی و توسعه: مهراب مساحی»

## اجرا
فایل `index.html` را با مرورگر باز کنید. اطلاعات روی همان دستگاه و همان مرورگر ذخیره می‌شود.

## محدودیت
جمله روزانه داخل خود برنامه نمایش داده می‌شود؛ این نسخه اعلان push یا پیام بیرون از برنامه ارسال نمی‌کند. برای اعلان روزانه، حساب کاربری امن، پایگاه‌داده و همگام‌سازی چنددستگاهی باید سرویس سمت سرور افزوده شود.
